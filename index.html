Häufige Fragen

Welche Zahlungsmethoden werden akzeptiert?
Wir akzeptieren alle gängigen Zahlungsmethoden: Kreditkarte (Visa, Mastercard), PayPal, Sofortüberweisung, SEPA-Lastschrift und Bitcoin. Die Abrechnung erfolgt monatlich oder jährlich mit attraktiven Rabatten für Jahreszahlungen.
Kann ich meinen Gameserver selbst verwalten?
Ja, alle unsere Gameserver werden mit vollständigem Zugriff geliefert. Du erhältst SSH-/FTP-Zugang und kannst alle Einstellungen selbst vornehmen. Alternativ bieten wir auch ein benutzerfreundliches Webinterface für einfache Verwaltung.
Wo befindet sich euer Rechenzentrum?
Unser Haupt-Rechenzentrum befindet sich in Frankfurt am Main, Deutschland. Es ist ISO 27001 zertifiziert und bietet höchste Sicherheitsstandards. Ein zweites Standort in Amsterdam ist in Planung.
Gibt es eine Mindestvertragslaufzeit?
Nein, alle unsere Server können monatlich gekündigt werden. Es gibt keine Mindestvertragslaufzeit oder automatische Vertragsverlängerung. Du zahlst nur für die Zeit, die du auch wirklich nutzt.
Wie schnell wird mein Server bereitgestellt?
Die meisten Server (VPS, Gameserver) werden innerhalb von 5-10 Minuten nach Zahlungseingang automatisch bereitgestellt. Root Server können bis zu 24 Stunden benötigen, da hier physische Hardware konfiguriert wird.
Kann ich meinen Server später upgraden?
Ja, alle unsere Server können jederzeit ohne Downtime hochskaliert werden. Mehr CPU, RAM oder Speicherplatz kann mit wenigen Klicks in unserem Kundenpanel hinzugebucht werden. Downgrades sind monatlich zum Abrechnungszeitpunkt möglich.
